Privacy

Nearby Eats is a static personal web app. It has no user accounts, advertising, analytics, developer-operated database, API key, or payment system.

Location

If you grant location permission, your browser supplies your current coordinates to the app. They are used to request nearby food data from public OpenStreetMap Overpass API servers. Nearby Eats does not intentionally store your precise coordinates permanently.

OpenStreetMap / Overpass

Search requests are sent directly from your browser to a public Overpass API service. Those services receive normal network information such as your IP address and the website referrer as part of serving the request.

Local storage

The app may remember small interface preferences and uses short-lived browser session caching to avoid repeatedly downloading the same nearby data.
