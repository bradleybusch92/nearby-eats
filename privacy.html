Privacy

Nearby Eats is a personal web app. It does not run its own analytics, advertising, user accounts, or developer-operated database.

Location

If you grant location permission, your browser supplies your current coordinates to the app. Those coordinates are used to request nearby place results from Google Maps Platform. The app does not intentionally persist your coordinates to its own storage.

Google Maps Platform

Searches use Google Maps Platform. Google may process request information under the Google Privacy Policy: policies.google.com/privacy.

API key

Your Google Maps API key is saved in this browser's local storage when you choose Save Key. It is not embedded in the app's GitHub source files by default. You can remove it from the Settings screen.
